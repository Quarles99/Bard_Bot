# Bard_Bot
A small music bot for discord.

**Status: complete, not under active development** (2026-08-12). The bot is
stable and stays deployed — everything works except playing age/login-gated
YouTube videos, which fail with an explanation instead of breaking. See
[`POSTMORTEM.md`](POSTMORTEM.md) for why, and `CLAUDE.md` for the
architecture if you're picking this up.
